# Science Toolkit

Install **Science Toolkit** from **Toolbox → Plugins → Refresh plugin list** in Scoreler 1.4 or later. It opens three tabs in one tool and works offline after installation.

- **Periodic table** — Search 118 elements by symbol, atomic number, English name or Chinese name. Select an element to see its period, group or series, and abridged standard atomic weight. Values in brackets are isotope mass numbers. Source: [IUPAC Periodic Table, 4 May 2022](https://iupac.org/what-we-do/periodic-table-of-elements/).
- **Physics equations** — Calculate the left-hand variable of 13 equations covering motion, forces, energy, waves, electricity and thermal physics. The calculator lists the expected units and assumptions. Reference: [OpenStax College Physics 2e](https://openstax.org/details/books/college-physics-2e).
- **Unit converter** — Convert length, area, volume, mass, time, speed, pressure, energy and absolute temperature. Reference: [NIST Guide to the SI, Appendix B](https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors).

The interface follows Scoreler’s language and theme. It replaces the separate Periodic table and Physics equations catalog entries. If you already installed those versions, uninstall them from your installed plugins list when you are ready to switch.
