# Physics equations

Choose one of 13 equations and enter the quantities in the units shown. Each calculation includes its assumptions. The calculator evaluates the displayed formula for its left-hand variable.

Reference: [OpenStax College Physics 2e](https://openstax.org/details/books/college-physics-2e). The calculator code and explanations were written for Scoreler.

Install in **Toolbox → Plugins**. The tool runs offline after installation.
