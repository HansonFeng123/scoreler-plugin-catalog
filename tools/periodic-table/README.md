# Periodic table

Search by symbol, atomic number, English or Chinese name. Press Enter to jump to the best match or select an element from the table.

Element identities and abridged values are from the [IUPAC Periodic Table, 4 May 2022](https://iupac.org/wp-content/uploads/2022/07/IUPAC_Periodic_Table-04May22_CRA.pdf). A bracketed number identifies an isotope’s mass number for an element without a standard atomic weight in that reference.

Install in **Toolbox → Plugins**. The tool runs offline after installation.
